# Conventions

## 목적

`conventions`는 Forday Android 코드를 어떤 모양으로 작성할지 정하는 공통 규칙이다.

## 포함

- Kotlin 네이밍과 함수 작성 방식
- Compose Route/Screen, stateful/stateless, Preview 규칙
- Clean Architecture, Mapper, DI 규칙
- 테스트 작성 기준

## 제외

- 기능별 코드 위치 지도
- 작업 절차
- 특정 AI 전용 지침
- 일회성 리뷰 결과
