# LLM Wiki Overview

## 목적

`llm-wiki`는 Forday Android 코드베이스의 지도다. AI가 작업할 때 "어디를 봐야 하는지" 빠르게 찾도록 돕는다.

## 포함

- 프로젝트 패키지 구조
- feature별 코드 위치
- Presentation, Domain, Data, Remote, Core의 책임과 위치
- Navigation, DI, Mapper 등록 위치
- 새 기능을 추가할 때 만들어야 하는 파일 위치

## 제외

- 코드 스타일 전문
- 에이전트 실행 절차
- 리뷰 리포트
- 특정 AI 전용 지침
