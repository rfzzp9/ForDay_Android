# LLM Wiki

## 목적

`llm-wiki`는 Forday Android 코드베이스의 위치와 구조를 설명하는 공통 지도다.

## 포함

- 패키지 구조
- 레이어별 책임과 위치
- 기능별 코드 위치
- Navigation, DI, Mapper 위치
- 새 기능을 추가할 때 확인할 파일 위치

## 제외

- 코드 스타일 전문
- 반복 작업 절차
- 특정 AI 전용 지침
- 일회성 리뷰 결과
