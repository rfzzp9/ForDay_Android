# Skills

## 목적

이 폴더에는 Codex 실행 스킬만 둔다. 코드베이스 지식, 코드 작성 규칙, 작업 절차는 `.agents/docs/`에 둔다.

## 활성 스킬

- `android-dev`: Android 기능을 만들거나 수정한다.
- `bug-analysis`: 깨진 동작의 원인을 분석하고 수정한다.
- `code-review`: 코드를 리뷰하거나 감사한다.

## 흡수된 이전 스킬 역할

예전의 세부 스킬은 아래처럼 세 활성 스킬로 흡수했다.

- feature scaffolding -> `android-dev`
- Android checklist review -> `code-review`
- architecture audit -> `code-review`
- security audit -> `code-review`
- performance audit -> `code-review`
- style audit -> `code-review`
