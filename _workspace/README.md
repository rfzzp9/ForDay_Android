# Workspace

## 목적

`_workspace`는 임시 작업 공간이다. 특정 시점의 리뷰 결과, 감사 리포트, 조사 메모, 마이그레이션 중간 산출물을 보관한다.

## 포함

- 일회성 코드 리뷰 결과
- 아키텍처/보안/성능/스타일 감사 리포트
- 작업 중 조사 메모
- 문서 마이그레이션 중간 비교표

## 제외

- 영구 코드베이스 지도
- 코드 작성 규칙
- 반복 작업 절차
- AI별 진입 지침

## 승격 규칙

`_workspace`의 내용이 장기적으로 필요하면 원본을 그대로 참조하지 말고 아래 위치로 정리해서 옮긴다.

- 코드 위치와 구조: `.agents/docs/llm-wiki/`
- 코드 작성 규칙: `.agents/docs/conventions/`
- 작업 순서: `.agents/docs/workflows/`

`_workspace`의 리포트는 과거 특정 시점의 결과이므로 최신 규칙으로 간주하지 않는다.
